# 教練操作說明

東勢國中棒球隊｜冒險訓練筆記本

---

## 一、登入

1. 打開球隊網站，在「☁️ 雲端登入」輸入帳號與登入碼。
2. 教練帳號是 `coach`。第一次登入後，建議到左邊「🔑 我的帳號」把登入碼改成自己記得住的（至少 8 個字，要有英文字母和數字）。
3. 登入狀態最多維持 6 小時，時間到會請你重新登入。
4. **忘記教練登入碼**：打開試算表 →「擴充功能 → Apps Script」→ 函式選單選 `resetCoachCode` → 按「▷ 執行」，新的登入碼會顯示在下方執行記錄。

> 登入頁下方的「🧪 示範模式」使用虛構資料，可以給球員或家長體驗功能，不會影響雲端資料。

## 二、帳號管理（教練後台 → 👥 球員與帳號）

| 要做的事 | 怎麼做 |
| --- | --- |
| 新增球員 | 填寫姓名、背號、年級、位置 → 按「新增球員」。畫面會顯示**帳號與登入碼**，請抄下來交給球員（關閉後無法再查看）。 |
| 新增家長帳號 | 在「新增教練或家長帳號」選「家長」，勾選對應的子女 → 按「建立帳號」。 |
| 球員或家長忘記登入碼 | 在帳號清單按「重設登入碼」，把新的登入碼交給對方。舊登入碼會立即失效。 |
| 球員離隊 | 在球員名單按「停用」，球員帳號同時停用，資料會保留。 |
| 永久刪除球員 | 在球員名單按紅色「刪除」，輸入球員姓名確認。會連同帳號、筆記、體能、目標、段考、遊戲紀錄一起刪除，**無法復原**（只能從每週備份找回）。 |
| 修改家長對應的子女 | 在帳號清單按該家長的「修改」。 |

## 三、每天會用到的功能

### 每日筆記（左邊「📒 棒球筆記」）
- 上方選擇球員，右邊「歷史筆記」點日期查看。
- 在「教練評語」寫下回饋 → 按「儲存評語」，球員會在自己的筆記中看到。

### 體能檢測（左邊「💪 體能檢測」）
選擇球員 → 選檢測項目 → 輸入數值 → 按「新增紀錄」。

| 項目 | 單位 | 輸入範例 |
| --- | --- | --- |
| 伏地挺身 | 次 | `25` |
| 仰臥起坐 | 次 | `32` |
| 立定跳遠 | 公分 | `200` |
| 1500 公尺 | 分:秒 | `6:45` 或 `6:45.30` |
| 150 公尺 | 秒 | `22.5` |
| 慣用手握力 | 公斤 | `28.5` |
| 揮棒速度 | km/h | `95.5` |
| 投球球速 | km/h | `92.4` |

輸錯了可以在「歷史紀錄」按「修改」或「刪除」。所有新增、修改、刪除都會記錄在操作紀錄中。

### 體能檢測系統（獨立網頁）
網址是球隊網站後面加上 `fitness.html`，或在「💪 體能檢測」頁右上角按「🏋️ 打開體能檢測系統」。用**同一個帳號與登入碼**登入，資料就是原本的體能紀錄（含舊系統匯入的），兩邊改任何一邊，另一邊都會看到。

| 分頁 | 用途 |
| --- | --- |
| 📊 全隊總覽／排行 | 「全隊總表」看每位球員 8 個項目的最新成績（▲綠色＝比上次進步、▼紅色＝退步）；「項目排行」看某個項目的名次或「進步幅度」排行，可以產生排行榜圖片傳到 LINE。上方可以選日期範圍（例如只看這學期）。 |
| ⏱️ 團體檢測（碼表） | 現場用手機最方便。① 點項目 → ② 點選這一組的球員 → ③ 開始檢測。**1500 公尺、150 公尺**：大家一起起跑時按「▶ 起跑」，誰到終點就按誰的名字，時間自動記下並排名次；按錯人按「↩️ 撤銷上一下」。1500 公尺可以選跑道長度「記圈數」，每次經過終點線按一下，畫面會顯示誰跑了幾圈，最後一圈就是成績。150 公尺分好幾組跑時，跑完一組按「⏹ 結束這一組」，碼表歸零，換下一組。**揮棒速度、投球球速**：每位球員最多測 10 次，每測一次輸入數字按「加入」，畫面會即時算出平均和最高；輸錯了點那一次的數字就能刪掉。儲存的成績是平均值，每一次的數字記在備註。其他項目：每位球員一個大輸入框（次數有 ＋／− 按鈕）。全部測完按「💾 儲存」。碼表跑的時候螢幕不會自動關閉；不小心重新整理或關掉頁面，碼表和成績都還在。 |
| ✍️ 全隊輸入 | 選檢測日期與項目 → 整份名單一次填完 → 按「💾 儲存」。輸入完按 `Enter` 會跳到下一位；沒來的球員留白。同一天已經輸入過的會顯示「已輸入」，改了會變成修改那一筆，不會多一筆。只要有一位數值不合理，整批都不會儲存，請照紅框修正。揮棒速度、投球球速可以在同一格輸入最多 10 次，用空白隔開（例如 `95 96.5 97`），會自動存平均值。 |
| 👤 個人紀錄 | 選球員看最新成績、隊內排名、成長折線圖、歷史紀錄（可修改／刪除），可以產生**個人報告圖片**傳給家長。 |
| 📤 匯出 Excel | 下載「最新成績總表」或「全部紀錄明細」（CSV 檔，Excel 可直接打開）。 |

用手機打開時，分頁會在螢幕最下方，全隊總表會變成一位球員一張卡片，不用左右滑。球員登入後只看得到「👤 個人紀錄」（自己的成績）；家長、老師不能進入這個系統。

### 匯入舊的體能檢測資料（教練後台 → 📥 匯入舊資料）
1. 貼上舊檔案的 Google 試算表網址 → 按「預覽」。預覽只會讀取，不會寫入，也不會修改舊檔案。
2. 確認筆數、學生名單和「不會匯入的紀錄」沒問題 → 按「確認匯入」。
3. 新增的學生會顯示「尚無帳號」，到「👥 球員與帳號」按「建立帳號」，把帳號與登入碼交給學生。
4. 同一份檔案再匯入一次也不會重複，可以放心。

### 段考成績（左邊「📝 段考成績」）
1. 「✏️ 輸入成績」分頁：選擇學年度、學期、第幾次段考、年級（年級決定科目）。
2. 表格一列是一位球員，直接輸入各科分數（0～100，可以有一位小數）。**沒考或還沒有成績的科目留空白**，不會被當成 0 分。
3. 按「💾 儲存這次段考的成績」。已經有成績的球員旁邊會出現 ●；再按一次儲存會更新成表格裡的分數。
4. 表格預設只顯示「這個年級」和「還沒設定年級」的球員；勾選「顯示所有球員」可以看全部。建議到「教練後台 → 👥 球員與帳號」幫球員填好年級。
5. 「👤 個人成績」分頁可以看每位球員的歷次成績、平均與變化圖；輸入錯了可以按「刪除」後重新輸入。
6. 球員只看得到自己的成績；家長只看得到自己孩子的成績。

| 年級 | 科目 |
| --- | --- |
| 一年級 | 國文、數學、英文、社會、自然、建教 |
| 二年級 | 國文、數學、英文、地理、歷史、公民、理化、建教 |
| 三年級 | 國文、數學、英文、地理、歷史、公民、理化、地科生物 |

### 對戰、血量與道具（球員使用）
- **⚔️ 對戰競技場**：野外對戰（PVE）每天 5 次；隊友挑戰（PVP）每天 3 次，同一位隊友一天只能挑戰一次。
- 隊友挑戰不是即時連線：對方的夥伴由電腦操控、以滿血出戰，不會讓對方的怪獸受傷。
- **血量（HP）**：對戰後怪獸會保留剩下的 HP；HP 歸零就要休息，每小時自然回復 25%（約 4 小時回滿）。
- **🎒 道具商店**：用遊戲點數購買回復藥水、高級回復藥、力量手套、防護護具。不能用真實金錢購買，捕捉球也不在商店販售。
- 對戰結果全部由雲端伺服器計算，球員無法自己修改。

### 與怪獸互動、親密度與進化（球員使用）
- 在「🥚 怪獸訓練」的「💕 互動」區，可以和夥伴（或在收藏中按「💕 互動」選另一隻）互動，增加**親密度**（0～100）：

| 互動 | 花費 | 效果 | 每隻怪獸每天 |
| --- | --- | --- | --- |
| 🤚 摸摸牠 | 免費 | 親密度 +2 | 3 次 |
| 🍙 餵點心 | 5 點 | 親密度 +4、回復 20% HP | 2 次 |
| ⚾ 一起玩球 | 免費 | 親密度 +4、經驗 +5 | 1 次 |

- **親密度進化**：球球丸、手套熊、梨梨寶、加油鸚、書包貓、桐花芽 這 6 種幼年型怪獸，親密度達到 **50** 就能進化（不看等級）。其他怪獸照舊用等級進化。
- 教練可以在「教練後台 → 🐾 怪獸與圖鑑 → 修改」調整「親密度進化」：填 0＝用等級進化；填大於 0 的數字＝親密度達到就能進化。
- 捕捉與進化都有動畫畫面；結果仍由雲端決定。

### 親師平台（左邊「🤝 親師平台」）— 家長、老師、教練三方
**邀請家長或老師加入（教練後台 → ✉️ 邀請碼）**
1. 選「家長」或「老師」，勾選對應的學生（家長＝自己的孩子；老師＝負責的學生），可以填備註方便辨認。
2. 按「產生邀請碼」，畫面會顯示 8 碼邀請碼和註冊網址，**只顯示這一次**，請抄下來交給對方。
3. 對方打開網址（或登入頁的「我是家長／老師，有邀請碼」），輸入邀請碼，**自己設定帳號、顯示名稱和密碼**，建立後直接登入。
4. 一組邀請碼只能用一次，14 天後失效；沒用到的可以按「作廢」。
5. 之後要調整家長／老師對應的學生，到「👥 球員與帳號 → 帳號清單」按「修改」。

**平台上有什麼（每位學生一個頁面）**
| 分頁 | 內容 | 誰可以寫 |
| --- | --- | --- |
| 📋 總覽 | 最近行程、最新留言、在校表現、課業、棒球學習、體能，一頁看完 | — |
| 💬 溝通區 | 家長、老師、教練互相留言（**學生本人看不到**） | 家長、老師、教練 |
| 🏫 在校表現 | 上課表現、作業繳交、學習態度、出缺席、品德行為 | 老師、教練 |
| 📒 棒球筆記 | 學生的每日筆記全文、教練評語、目標進度 | 學生寫筆記，教練寫評語 |
| 📝 課業 | 段考成績 | 教練 |
| 📅 行程 | 練習、比賽、考試、學校活動 | 教練（全隊或個人）、老師（自己的學生） |

- 家長只看得到自己孩子；老師只看得到自己負責的學生；**學務處與教練看得到全部**。
- 有多位學生的人（老師、學務處、教練）上方會有三個分頁：
  - **👥 全部學生一覽**：每位學生的最新留言、在校表現、近 14 天筆記天數、最近段考平均、7 天內行程，點姓名看詳細。
  - **📢 群發訊息**：勾選學生（可「全選」）→ 寫一次訊息 → 一次放進每位學生的溝通區。刪除群發訊息時可以從所有學生一起刪除。
  - **👤 個別學生**：單獨看一位學生、單獨留言。

**學務處帳號**
- 「👥 球員與帳號 → 新增帳號」角色選「學務處」，不用勾選學生，會**自動看得到全部在籍學生**（之後新增的學生也會自動加入）。
- 已經用「老師」建立的學務處帳號：在帳號清單按「修改」，角色改成「學務處」→ 儲存。
- 學務處可以：查看每位學生、群發訊息、單獨留言、寫在校表現、新增全體或個人行程、查看段考成績；**不能**使用教練後台。
- 球員在首頁會看到「最近行程」（全隊與自己的），但看不到溝通區和在校表現。

### 球隊管理（左邊「📋 球隊管理」）
資料存在**另一份獨立的試算表「東勢國中棒球隊｜球隊管理 資料庫」**（不會讓原本的資料庫變大）；頁面右上角「📂 打開球隊管理試算表」可以直接打開。球員名單沿用「👥 球員與帳號」裡的名單。

| 分頁 | 做什麼 | 誰看得到 |
| --- | --- | --- |
| 📅 一週練球 | 每天選「練球／休息／比賽／其他」，填時間、地點、內容、備註。可「複製上週的安排」或「快速填入」；「📋 複製 LINE 通知文字」可以直接貼到群組 | 全部（球員、家長首頁也會看到「這週練球」） |
| 🗓️ 練球安排 | 按「安排這一週」→ 每一天按「安排這天」：同一個畫面列出晨練／午休／下午／晚間，勾選要練的時段直接填內容、人員、地點（同時段分組可加「自訂時段」）。**同一天每位球員只能排在一個時段**，已排過的人會變灰；排了全隊的那天不能再排其他時段。可「也套用到其他天」、「完成，接著排下一天」、「複製上週」，最後「💾 儲存這一週」；可產生 LINE 圖片 | 全部（球員、家長只看到全隊與自己／孩子參加的時段） |
| ✅ 出缺席 | 選日期 →「還沒點的全部設為出席」→ 點選遲到、事假、病假等 → 儲存。下方「出席統計」可選期間、下載 Excel | 只有教練 |
| 👥 球員通訊錄 | 每位球員的生日、班級、投打、身高體重、監護人與電話、健康注意事項。可下載通訊錄 | 只有教練 |
| 📷 球員大頭照 | 把照片放進雲端硬碟名稱有「大頭照」的資料夾（例如「05 球員大頭照」），在通訊錄按「☁️ 從雲端資料夾匯入大頭照」→ 選資料夾 →「讀取照片並配對」→「匯入」，檔名的國一／國二／國三和括號會自動忽略；也可以在通訊錄按「編輯」→「選擇照片／拍照」，或按「📷 一次上傳很多張大頭照」，照片檔名取成球員姓名（例如 王小明.jpg）會自動對到人，對不到的用下拉選單選。上傳時自動縮小，原圖不會被改動。照片存在雲端硬碟「東勢國中棒球隊 球員大頭照」資料夾（不公開分享），也會出現在賽事的「號碼名單圖片」 | 全隊 |
| 💰 預算管理 | 先依年度新增「支出項目＋預算」（也可以新增預計收入），再一筆一筆記收支。每個項目自動算出已用、剩餘、使用率；用到 80% 會提醒，超過會顯示超支 | 只有教練 |
| 🏆 賽事管理 | 新增盃賽／聯賽（日期、地點、報名截止、報名費、參賽名單），再新增每一場比賽與比分，自動算戰績。參賽名單旁「👕 安排球衣號碼」用下拉選單選號碼（0～99、00，不會重複），「⚡ 自動產生號碼」會沿用上一場的號碼；「🖼️ 號碼名單圖片」可傳 LINE。號碼只在這場賽事出現，平常頁面不顯示 | 全部（報名費只有教練看得到） |

- **傳到 LINE 群組**：「一週練球」和「出缺席」（儲存點名後）都有「🖼️ 產生 LINE 圖片」。手機按「📤 分享到 LINE」選群組；電腦按「⬇️ 下載圖片」再拖進 LINE。出缺席圖片預設**不顯示請假原因**，需要時勾選「圖片上顯示請假原因」。
- 出席率＝（出席＋遲到＋早退）÷ 點名次數；請假也算在點名次數內。
- 預算的金額、收支的新增／修改／刪除都會寫入「🗂️ 操作紀錄」。
- 刪除球員時，他的點名紀錄與個人資料也會一起刪除。

### 任務確認（教練後台 → 📋 任務與獎勵）
- 「待確認的任務回報」會列出球員回報的任務，確認後按「核准」，球員就能領取獎勵；不符合就按「退回」。
- 「完成今日棒球筆記」「防護知識測驗」這兩種任務由系統自動檢查，不需要教練確認。

### 目標檢核（教練後台 → 🎯 目標與進度）
- 球員申請完成的檢核點會出現在「待核准的檢核點」，按「核准」後才會計入進度。
- 「目標期限設定」可以調整短期、中期、長期目標的預設天數。

## 四、內容管理

## 五、資料與備份

- 所有資料都存在 Google 試算表「東勢國中棒球隊 資料庫」。**請不要把試算表分享給別人**，也不要手動修改 `Users` 工作表的 `codeHash`、`codeSalt` 欄位。
- 球隊管理（練球、點名、通訊錄、預算、賽事）的資料存在另一份試算表「東勢國中棒球隊｜球隊管理 資料庫」，同樣**不要分享給別人**。
- **自動備份**：每週一凌晨 3 點自動複製一份到雲端硬碟資料夾「東勢國中棒球隊 資料庫備份」（兩份試算表都會備份）。
- **立即備份**：Apps Script → 函式選單選 `backupNow` → 按「▷ 執行」。
- **還原**：
  - 方法一：在試算表選單「檔案 → 版本記錄」，選擇過去的時間點還原。
  - 方法二：打開備份資料夾裡的某一份備份檔，把需要的資料複製回來。
- 「教練後台 → 🗂️ 操作紀錄」可以查看誰在什麼時候做了哪些重要操作。

## 六、常見問題

| 狀況 | 處理方式 |
| --- | --- |
| 畫面顯示「登入已過期」 | 重新登入即可。 |
| 畫面顯示「無法連線到雲端」 | 檢查網路後再操作一次。失敗的操作不會被儲存，「🔌 同步錯誤」會留下紀錄。 |
| 球員說領不到獎勵 | 先確認任務是否已「核准」。同一個任務在同一天（或同一週）只能領一次。 |
| 球員說探索次數用完 | 每人每天 3 次，隔天自動恢復。 |
| 想讓全隊重新看到新版網頁 | 請對方重新整理頁面。 |

## 七、更新程式時（由開發者協助）

**不用再手動貼程式。** 在專案資料夾執行一個指令就會自動完成：

```bash
npm run deploy:gas
```

它會依序：在電腦上跑完全部自動測試 → 把 `Code.gs`、`Tests.gs` 送到 Apps Script → 更新網站正在用的部署作業（網址不變）→ 確認網站已經在用新版本。測試沒通過就不會上傳。

第一次設定（已完成，換電腦時才需要重做）：
1. 到 https://script.google.com/home/usersettings 打開「Google Apps Script API」。
2. 執行 `npx.cmd clasp login`，用球隊的 Google 帳號登入並允許。
3. 在 `apps-script/.clasp.json` 填入指令碼 ID（Apps Script →「專案設定」→「指令碼 ID」）。

手動方式（備用）：Apps Script 貼上 `Code.gs`、另一個檔案 `Tests` 貼上 `Tests.gs` → 儲存 →「部署」→「管理部署作業」→ ✏️ 編輯 →「版本」選「新版本」→「部署」。
